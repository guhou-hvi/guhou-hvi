我是哈尔滨工业大学航天学院博士研究生，研究如何结合传感信号、物理模型与数值仿真，支持航天器损伤评估和防护设计。我的工作连接科学机器学习、仿真数据管线与可审计科研 Agent，关注预测对工程判断的实际价值、证据的可追溯性，以及科学计算软件的可靠性。

## 代表项目

- **[Whipple RPP](https://github.com/guhou-hvi/whipple-rpp-benchmark)** — 从声发射信号预测含损伤 Whipple 防护结构的剩余防护性能。通过弹道极限方程构建空间监督目标，在模型比较中同时考察全局重构、薄弱区域与外推表现。
- **[AE-PDSM](https://github.com/guhou-hvi/ae-pdsm)** — 将声发射信号映射为穿孔状态与二维点蚀损伤形貌，连接原位感知与航天器损伤定量评估。
- **[elsevier-figure-style](https://github.com/guhou-hvi/elsevier-figure-style)** — 独立、非官方的科研绘图工具及 Agent Skill，将公开的期刊绘图要求转化为可复用样式、自动检查与视觉审查流程。
