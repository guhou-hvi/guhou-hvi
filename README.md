## Selected projects

- **[Whipple RPP](https://github.com/guhou-hvi/whipple-rpp-benchmark)** — Predicting residual spacecraft protection from acoustic signals; I built the simulation/training pipeline and surrogate-model comparisons.
- **[AE-PDSM](https://github.com/guhou-hvi/ae-pdsm)** — Predicting perforation and pitting morphology from acoustic signals; I built the FE–SPH data pipeline, model and validation workflow.
- **[elsevier-figure-style](https://github.com/guhou-hvi/elsevier-figure-style)** — Independent, unofficial research-figure tooling; I developed Python/R styles, Python source checks, export validation and Agent visual QA.
